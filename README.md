# CarReveal
Github Repo for my Computer Graphics project made in Blender

Sto riscontrando problemi nella fase di rendering per l'export dell'animazione.
Pertanto registrò un live screencast direttamente in Blender, mostrando il prodotto(l'animazione) ed il rendering software (Blender), rispettando in ogni caso le direttive per la consegna.

![](https://github.com/danieleene/CarReveal/blob/main/porsche.jpeg)




Considerazioni sull’esperienza:

Computer Graphics mi ha permesso di fare la mia prima esperienza in Blender,  lavorando su una piccola animazione 3D di un car reveal, con il motore grafico EEVEE.
Mi sono cimentato con interesse nell’animazione della scena, nell’illuminazione e, con qualche problema, anche nella parte di rendering.
È decisamente un ambito di interesse, pieno di sfide ma anche soddisfazioni che ha destato la mia curiosità ed entusiasmo che sono stati ripagati da questa utile, oserei dire in prospettiva futura perché no, esperienza.
